# relay

DERP-style relay server. Used as fallback when peers cannot establish a direct
connection (e.g. behind symmetric NAT).

## Status

Pre-alpha scaffolding. No code yet.

- Go 1.23+
- HTTPS:443 (relay), STUN udp/3478
