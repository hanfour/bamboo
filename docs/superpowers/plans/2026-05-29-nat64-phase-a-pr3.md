# NAT64 Phase A — PR 3 (Client tunnels + MagicDNS + E2E) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring up the IPv6 overlay address on the actual client tunnel interfaces (CLI + Apple) and wire MagicDNS to answer AAAA, so two peers can reach each other on both families — the final PR of NAT64 Phase A.

**Architecture:** PR 1 gave every peer an `ip6` (DB → proto → `/api/v1/peers` JSON + register response self/peers). PR 2 made one ACL rule emit both `<v4>/32` and `<v6>/128` in `AllowedIPs`. AllowedIPs already flow through both clients unfiltered (mixed-family CIDRs parse fine), so PR 3 only needs to add each peer's **own** v6 address to its tunnel interface and feed peers' v6 into MagicDNS. CLI assigns the interface address via `netlink` (not `ip` shell-out); Apple lets WireGuardKit's adapter derive `NEIPv6Settings` from the `TunnelConfiguration.interface.addresses` array — so on both sides "add the v6 interface address" means appending one more address to an existing list, not new platform plumbing.

**Tech Stack:** Go (`clients/core`, `clients/cli`, vishvananda/netlink), Swift (`clients/apple`, WireGuardKit, NetworkExtension), PostgreSQL (migration verification).

**Spec:** `docs/design/2026-05-28-nat64-phase-a-overlay-ipv6.md` §7 (client tunnel dual-stack, rows 1–2), §8 (MagicDNS), §3/§10 (migration backfill verification, deferred from PR 1). **Builds on:** PR 1 (#232) + PR 2 (#233).

## Pre-flight context for the implementer

- **Self vs peers:** a client learns its OWN overlay v4 from the register response's `self` peer (`resp.Self.Ip` in Go proto; `resp.self_.ip` in Swift). PR 1 added `ip6` to that same self peer. This PR reads `self.ip6` and assigns it to the local interface. The MagicDNS change instead reads OTHER peers' `ip6` for AAAA answers.
- **AllowedIPs need no change:** Go `clients/core/wg/config.go` parses every AllowedIPs CIDR via `netip.ParsePrefix` (no family filter); Apple `TunnelConfigurationBuilder` parses each via `IPAddressRange(from:)`. Both already accept the `<v6>/128` entries PR 2 emits. Do **not** add family handling there.
- **Linux-only file:** `clients/core/device/device_linux.go` is `//go:build linux`; on a dev Mac it is NOT compiled by `go build ./...` (the `device_other.go` stub is). Verify it with `GOOS=linux go vet ./clients/core/device/`.
- **Apple testability:** the `AppleSharedTests` target compiles `Shared/BambooClient.swift` (so `PeerJSON` decoding is unit-testable) but NOT `TunnelConfigurationBuilder.swift` / `ConnectionViewModel.swift` (they import WireGuardKit/NetworkExtension, which can't link into an xctest bundle). So those two are verified by **compile** (`make apple-build-macos`) only; MagicDNS behaviour is already covered by `MagicDNSResolverTests`/`MagicDNSPeerStoreTests`.
- Go tools may be off PATH: prepend `PATH="$PATH:/Users/hanfourmini/go/bin"` if `go` is missing. Apple targets need `xcodegen` + Xcode (this is macOS).
- **Legacy fallback stays v4-only (intentional):** when the controller supplies no AllowedIPs (pre-#149 / no policy), both clients derive a single `<v4>/32` for a peer. PR 2 makes the controller always emit dual-family, so the fallback is a legacy edge; leave it v4-only on both platforms for parity. Do not touch `aclAllowedIPs` (Apple) or the `peer.IP`-derived fallback (Go).

```go
func (d *linuxDevice) applyAddress(cfg *wg.DeviceConfig) error {
	if err := d.addAddr(cfg.Address); err != nil {
		return err
	}
	// Dual-stack (NAT64 Phase A): add the IPv6 ULA when the controller
	// supplied one. Zero/invalid on a pre-#232 controller — skip then.
	if cfg.Address6.IsValid() {
		if err := d.addAddr(cfg.Address6); err != nil {
			return err
		}
	}
	return nil
}

// addAddr assigns a single prefix to the link, idempotent on EEXIST.
func (d *linuxDevice) addAddr(p netip.Prefix) error {
	addr := &netlink.Addr{
		IPNet: &net.IPNet{
			IP:   p.Addr().AsSlice(),
			Mask: net.CIDRMask(p.Bits(), p.Addr().BitLen()),
		},
	}
	if err := netlink.AddrAdd(d.link, addr); err != nil && !isExist(err) {
		return fmt.Errorf("addr add %s: %w", p, err)
	}
	return nil
}
```

Add `"net/netip"` to the import block if it is not already imported (check the top of the file; the rest of the package uses `netip` so it likely is — if already present, do not duplicate it).
