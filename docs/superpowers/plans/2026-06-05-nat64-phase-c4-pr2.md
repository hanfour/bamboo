# NAT64 Phase C4 PR 2 — config surfacing + channel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the tenant DNS64 config (`dns64Enabled` + `nat64Prefix`) from the controller to the Apple DNS proxy — surfacing it on the REST register response, decoding it client-side, and pushing it across the App-Group channel (which also revives the currently-dormant iOS MagicDNS).

**Architecture:** The Apple client registers over REST, but `peerRegisterResponse` omits the NAT64 fields that the gRPC `RegisterResponse` already carries — so a tiny controller change surfaces them. Swift decodes them, and `ConnectionViewModel` persists them via a new NAT64 config sidecar in `MagicDNSPeerStore` (the same App-Group file channel the peer map uses). Fixing that channel for iOS — its base path is hard-coded to macOS-only `/Users/Shared`, leaving the iOS extension's store empty — is a prerequisite: the path becomes platform-conditional (macOS keeps `/Users/Shared`; iOS uses the already-entitled App Group container). PR 3 (the provider 2-stage upstream) reads this config to gate synthesis.

**Tech Stack:** Go (controller, real-Postgres e2e); Swift / Foundation (Apple client + DNS proxy); xcodegen project; goose migrations + docker Postgres for the controller test.

## Background the implementer needs

- **Spec:** `docs/design/2026-06-03-nat64-phase-c4-apple-dns64.md` §3 (iOS channel prerequisite) + §4.2 (this PR) + §8 PR 2.
- **The fields are tenant-scoped** and already resolved server-side: the gRPC register handler sets `Dns64Enabled: tenant.DNS64Enabled` and `Nat64Prefix: nat64.ResolvePrefix(tenant.NAT64Prefix)` (`apps/controller/internal/handlers/coordinator.go:440-441`). The REST handler `apiPeersRegister` builds its JSON response from that same proto `resp`, so surfacing them is two struct fields + two assignments — no new tenant fetch.
- **Apple registers over REST**, decoding `BambooClient.RegisterResponse` (`clients/apple/Shared/BambooClient.swift:123`). REST JSON keys are camelCase (`policyRevision`, `preferredRegion`), matching the Go `json:"...,omitempty"` tags.
- **The App-Group channel is `MagicDNSPeerStore`** (`clients/apple/Shared/MagicDNSPeerStore.swift`). It atomically writes a JSON file (tmp + `Darwin.rename`) and is unit-tested via an `init(path:)` seam. Its base dir is hard-coded `/Users/Shared/dev.hanfour.bamboo` for ALL platforms — correct on macOS (the DNSProxy *System Extension* can't share the App Group container, issue #154) but unreachable in the iOS sandbox, so **iOS MagicDNS is dormant today**. Both iOS targets already entitle the App Group `group.dev.hanfour.bamboo`.
- **`MagicDNSPeerStore.swift`, `BambooClient.swift` are in `AppleSharedTests`** (directly compiled → `internal` symbols visible to tests). **`ConnectionViewModel.swift` is NOT** (it imports NetworkExtension), so its one-line wire-up is compile-verified, not unit-tested.
- **Controller e2e tests** live in `apps/controller/test/e2e/`, gate on `DATABASE_URL_TEST` (skip if unset / `-short`), and exercise the in-process HTTP fixture via `postJSON(t, f.httpURL+"/api/v1/peers/register", body) → jsonResponse{body []byte}`. Tenant state is seeded with `repo.NewTenants(f.pool).SetNAT64Config(ctx, id, prefix, enabled)`.

- [ ] **Step 2: Add the NAT64Config type + sidecar accessors.** Inside `public struct MagicDNSPeerStore { … }` (after the `peers()` method), add:

```swift
    /// NAT64Config is the tenant's DNS64 settings, pushed from the app to the
    /// DNS proxy alongside the peer map (NAT64 Phase C4). Stored in a sibling
    /// "nat64-config.v1.json" file in the same directory as the peer map.
    public struct NAT64Config: Codable, Equatable {
        public let dns64Enabled: Bool
        public let nat64Prefix: String
        public init(dns64Enabled: Bool, nat64Prefix: String) {
            self.dns64Enabled = dns64Enabled
            self.nat64Prefix = nat64Prefix
        }
    }

    /// configURL is the NAT64 sidecar, a sibling of the peer-map file (so the
    /// init(path:) test seam covers it without extra plumbing).
    private var configURL: URL {
        url.deletingLastPathComponent().appendingPathComponent("nat64-config.v1.json")
    }

    /// setNAT64Config persists the tenant DNS64 settings for the DNS proxy.
    /// Atomic write (tmp + rename), mirroring setPeers.
    public func setNAT64Config(_ cfg: NAT64Config) {
        do {
            try FileManager.default.createDirectory(
                atPath: configURL.deletingLastPathComponent().path,
                withIntermediateDirectories: true,
                attributes: [.posixPermissions: 0o700])
            let data = try JSONEncoder().encode(cfg)
            let tmp = configURL.deletingLastPathComponent()
                .appendingPathComponent(".nat64-config.\(UUID().uuidString).tmp")
            try data.write(to: tmp, options: [.atomic])
            try FileManager.default.setAttributes(
                [.posixPermissions: 0o600], ofItemAtPath: tmp.path)
            if Darwin.rename(tmp.path, configURL.path) != 0 {
                let err = errno
                _ = try? FileManager.default.removeItem(at: tmp)
                NSLog("[MagicDNSPeerStore] nat64 rename(\(tmp.path) → \(configURL.path)) failed errno=\(err)")
            }
        } catch {
            NSLog("[MagicDNSPeerStore] nat64 write failed at \(configURL.path): \(error)")
        }
    }

    /// nat64Config reads the sidecar, defaulting to "off" when missing or
    /// unreadable (a tenant without DNS64, or a pre-C4 app).
    public func nat64Config() -> NAT64Config {
        guard FileManager.default.fileExists(atPath: configURL.path) else {
            return NAT64Config(dns64Enabled: false, nat64Prefix: "")
        }
        do {
            let data = try Data(contentsOf: configURL)
            return try JSONDecoder().decode(NAT64Config.self, from: data)
        } catch {
            NSLog("[MagicDNSPeerStore] nat64 read failed at \(configURL.path): \(error)")
            return NAT64Config(dns64Enabled: false, nat64Prefix: "")
        }
    }
```
