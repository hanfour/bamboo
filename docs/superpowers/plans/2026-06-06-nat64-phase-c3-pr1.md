# NAT64 Phase C3 PR 1 — CLI egress self-report Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the NAT64 egress CLI report its Tayga translator's true liveness on the heartbeat, so the controller (PR 2/3) can fail over off an unhealthy egress.

**Architecture:** The Tayga process supervisor gains a real liveness flag (`Alive()`) distinguishing "translating" from "crash-looping in backoff"; `Manager.Healthy()` and `Reconciler.ActiveHealth() *bool` surface it (nil when this box isn't the active egress); the REST heartbeat carries a new `nat64EgressHealthy *bool` side-channel populated from the reconciler. The controller ignores the new JSON field until PR 2, so this PR is behavior-neutral on the controller.

**Tech Stack:** Go; `clients/core/nat64egress` (Manager/Reconciler/supervisor) + `clients/cli` (heartbeat REST + daemon loop). go.work multi-module.

- [ ] **Step 3: Add the lifecycle flag + accessor** to `clients/core/nat64egress/supervisor.go`.

Add a `childUp bool` field to the struct (under the existing `mu`):
```go
type supervisor struct {
	startFn func(context.Context) (runnable, error)
	backoff time.Duration

	mu      sync.Mutex
	cancel  context.CancelFunc
	stopped chan struct{}
	childUp bool // true while a started child is running (guarded by mu)
}
```

Set/clear it inside `loop` around the start + Wait, and clear it on Stop. Replace the existing `loop` body's start/wait section so it maintains `childUp`:
```go
func (s *supervisor) loop(ctx context.Context, stopped chan struct{}) {
	defer close(stopped)
	for {
		r, err := s.startFn(ctx)
		if err != nil {
			if ctx.Err() != nil {
				return // Stop() cancelled us mid-start; not a real failure
			}
			slog.Warn("nat64 egress: tayga start failed", "err", err)
		} else {
			s.setChildUp(true)
			waitErr := r.Wait()
			s.setChildUp(false)
			if ctx.Err() != nil {
				return // Stop() cancelled us; the exit was expected
			}
			slog.Warn("nat64 egress: tayga exited; restarting", "err", waitErr)
		}
		select {
		case <-ctx.Done():
			return
		case <-time.After(s.backoff):
		}
	}
}

func (s *supervisor) setChildUp(up bool) {
	s.mu.Lock()
	s.childUp = up
	s.mu.Unlock()
}

// Alive reports whether a supervised child is currently running (not
// crash-looping in backoff and not stopped). linuxManager.Healthy uses
// this to distinguish a translating egress from one whose tayga keeps
// dying.
func (s *supervisor) Alive() bool {
	s.mu.Lock()
	defer s.mu.Unlock()
	return s.childUp
}
```

Also clear `childUp` in `Stop` so `Alive()` is false promptly after Stop (the loop also clears it via the deferred path, but Stop should not depend on loop scheduling):
```go
func (s *supervisor) Stop() {
	s.mu.Lock()
	cancel, stopped := s.cancel, s.stopped
	s.cancel = nil
	s.childUp = false
	s.mu.Unlock()
	if cancel == nil {
		return
	}
	cancel()
	<-stopped
}
```

Add the Reconciler method (anywhere after `Reconcile`):
```go
// ActiveHealth returns this peer's NAT64 egress health for the heartbeat
// self-report: nil when the peer is NOT the active egress (the controller
// never told it to translate, so it has nothing to report), otherwise a
// pointer to the translator's current liveness. The controller treats nil
// as "judge by staleness only" (NAT64 Phase C3).
func (r *Reconciler) ActiveHealth() *bool {
	r.mu.Lock()
	defer r.mu.Unlock()
	if !r.applied || !r.lastActive {
		return nil
	}
	h := r.mgr.Healthy()
	return &h
}
```

func RunHeartbeat(ctx context.Context, hb Heartbeater, peerID string, discover EndpointDiscoverer, reportBytes BytesReporter, reportNAT64Health NAT64HealthReporter) {
	t := time.NewTicker(HeartbeatInterval)
	defer t.Stop()

		select {
		case <-ctx.Done():
			return
		case <-t.C:
